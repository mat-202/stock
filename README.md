# لوحة تحليل الدورات الزمنية 🔄

نسخة منظمة بكود بايثون (بدل الكود المولّد من Gemini) لنفس فكرة موقعك:
اختيار السوق، نجم/الأقل أداءً، مطابقة التواريخ بين الدورات، وتفاصيل كل سهم
(السعر الحالي، المستهدف النسبي، بداية/نهاية الدورة، شهر القمة المتوقع).

## هيكل الملفات

| الملف | المسؤولية |
|---|---|
| `cycle_engine.py` | رياضيات الدورات (الطول، القمة، التوقع، مطابقة التواريخ) — بدون إنترنت |
| `data_provider.py` | جلب الأسعار الحية/التاريخية عبر yfinance + تصنيف شكل الشمعة |
| `analytics.py` | المستهدف النسبي + لوحة المتصدرين (يجمع بين الدورات والأسعار) |
| `config.py` | **هنا تضيف/تعدّل الأسهم وتواريخ دوراتها فقط** |
| `app.py` | واجهة Streamlit |

## التشغيل محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

## إضافة سهم جديد أو تعديل دورة

افتح `config.py` فقط — لا تحتاج تلمس أي ملف آخر:

```python
amd = TickerCycles(ticker="AMD", name="إيه إم دي", market="nasdaq")
amd.add_cycle(start="2023-01", end="2025-02")   # دورة مكتملة (بدون peak إن لم تُحدَّد)
amd.add_cycle(start="2025-04", end="2027-06", peak="2026-05")
NASDAQ_STOCKS["AMD"] = amd
```

- كل ما سجّلت دورات تاريخية أكثر لسهم، صار متوسط الطول وموقع القمة أدق.
- أسهم تاسي تُكتب بدون `.SR` — الكود يضيفها تلقائيًا عند الجلب.

## النشر كموقع (بدل GitHub وحده)

GitHub يخزّن الكود فقط ولا يشغّله. لتشغيله كموقع فعلي مجانًا:

1. ارفع هذا المجلد كمستودع على GitHub (يتضمن `app.py` و `requirements.txt`).
2. روح إلى https://share.streamlit.io وسجّل دخول بحساب GitHub.
3. اختر "New app" → اختر المستودع → حدد `app.py` كملف رئيسي → Deploy.
4. أي تعديل تسويه على `config.py` وترفعه لـ GitHub ينعكس تلقائيًا على الموقع.

## ملاحظات

- المستهدف النسبي وأسلوب مطابقة الشموع (تصنيف "ضغط شراء / اختبار مقاومة...")
  اجتهاد إحصائي مبني على شكل الشمعة، وليس تحليلًا فنيًا معتمدًا أو توصية استثمارية.
- إذا كان موقعك الحالي يستخدم مصدر بيانات غير yfinance (API مدفوع مثلاً)،
  عدّل فقط الدوال داخل `data_provider.py` والباقي يبقى كما هو.
